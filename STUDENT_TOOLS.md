## 💡 Jak weryfikować status studenta?

Większość powyższych usług wymaga potwierdzenia statusu studenta polskiej uczelni. Najczęstsze metody to:

1. **Adres e-mail w domenie uczelni (`@*.edu.pl`)**: Najszybsza i najczęstsza metoda weryfikacji.
2. **Platforma SheerID / UNiDAYS**: Zewnętrzne systemy weryfikujące, często wymagające przesłania zdjęcia **Elektronicznej Legitymacji Studenckiej (ELS)** lub zaświadczenia z dziekanatu.
3. **GitHub Student Developer Pack**: Raz zweryfikowane konto GitHub Education daje natychmiastowy dostęp do kilkudziesięciu innych partnerstw i narzędzi bez ponownej weryfikacji.
4. **Międzynarodowa Legitymacja ISIC**: Używana jako alternatywny dokument potwierdzający status w wybranych serwisach zagranicznych.
